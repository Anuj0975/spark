CSS selectors are used to target and style specific HTML elements on a webpage. They are categorized into five main types.
1. Simple SelectorsSimple selectors target elements directly based on their name, ID, class, or universal presence.
Universal Selector (*): Matches every single element on the page.
Element / Type Selector (p, div): Targets all HTML tags of that specific name.
Class Selector (.classname): Targets all elements containing that specific class attribute.
ID Selector (#idname): Targets a single, unique element with that specific id attribute.
2. Combinator SelectorsCombinators use symbols to select elements based on their exact structural relationship to other elements in the HTML tree.
Descendant Selector (space): Matches all nested target elements inside a parent, regardless of depth.
Child Selector (>): Matches only the immediate, direct children of a parent element.
Adjacent Sibling Selector (+): Matches an element that directly follows another element at the same level.
General Sibling Selector (~): Matches all sibling elements that follow a specified element.
3. Attribute SelectorsThese selectors match elements if they contain a specific HTML attribute or attribute value.
Presence ([disabled]): Matches any element carrying the specified attribute.
Exact Value ([type="text"]): Matches elements with the exact attribute value.
Substring ([href*="login"]): Matches elements where the attribute contains a specific phrase anywhere within it.
4. Pseudo-class SelectorsPseudo-classes use a colon (:) to target elements only when they enter a specific state or condition.
User Interaction (:hover, :focus): Styles an element when a user interacts with it.Structural (:first-child, :nth-child(2)): Styles elements based on their order among sibling elements.Negation (:not(.active)): Excludes specific elements from being styled.
5. Pseudo-elements SelectorsPseudo-elements use double colons (::) to target and style a specific, sub-component part of an element.
Generated Content (::before, ::after): Inserts decorative content before or after the element's actual content
.Text Selection (::first-line, ::placeholder): Styles only the first line of a paragraph or the placeholder text inside an input field.
